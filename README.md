# Hamnal — 주화면 프로토타입

Figma **2팀 망초생 → `디자인시스템_최종` 페이지 → `Design` → 주화면 1–10** 프레임을
클릭 가능한 웹 프로토타입으로 옮긴 것입니다.

프로토타입 전용입니다. **서버·DB·CRUD 없음** — 모든 데이터는 `js/data.js`의 목업이고,
새로고침하면 초기 상태로 돌아갑니다.

## 실행

`index.html`을 브라우저로 열면 끝입니다. (더블클릭 또는 크롬에 드래그)
빌드 도구나 Node.js 설치가 필요 없습니다.

## 동작하는 인터랙션

- 하단 탭 `대화` → 대화 목록 / `홈` → 홈
- 대화 목록의 방을 누르면 그 방 제목으로 채팅방 진입
- FAB(＋) → 새 대화 → 캐릭터 선택(멜랑·코치) → 첫 인사 화면(주화면 4)
- 추천 문구 탭 또는 입력창 전송 → 내 말풍선 + 0.6초 뒤 자동 응답
- **추천 문구 `내가 잘 하고 있는지 모르겠어` → 주화면 5(진행 중 대화) 상태로 이어짐**
- **추천 문구는 첫 발화가 나가면 사라짐** (탭이든 직접 입력이든). 사라진 만큼 메시지 영역이 넓어짐
- **전송 버튼은 입력창이 비어 있으면 회색·비활성, 내용을 치면 노란색(`#FFC320`)으로 활성화**
- **첫 메시지를 보내면 대화방 제목이 `새대화` → 대화 내용 요약으로 바뀌고, 대화 목록 맨 위에도 추가됨**
- 헤더 우측 케밥(⋯) → 대화방 메뉴(고정 / 이름변경 / 삭제)
- 홈 좌측 `오늘운세` → 운세 모달, `출석체크` → 출석 캘린더 → CTA 누르면 씨앗 도착 카드
- 목록의 고정 표시는 **꽉 찬 핀**(`#B8B8B8`), 메뉴의 고정 아이콘은 **외곽선 핀**(`#211A11`) — 서로 다른 에셋입니다
- 이름변경 팝업: 글자수 카운터 동작, `변경하기` 누르면 헤더·목록 제목이 실제로 바뀜
- 삭제 팝업: `삭제하기` 누르면 목록에서 제거, 마지막 방을 지우면 빈 상태 화면으로

## 폴더 구조

```
index.html            폰 프레임 + 화면 인덱스 셸
css/style.css         디자인 토큰과 전체 스타일
js/data.js            목업 데이터 + 에셋 경로
js/screens.js         화면 10종 렌더 함수
js/app.js             라우터 + 인터랙션 핸들러
assets/img/           Figma에서 받은 이미지 (케이지, 캐릭터, 아바타)
assets/icon/          Figma에서 받은 아이콘 (탭바, 말풍선, 메뉴 등)
assets/font/          폰트 → 아래 "필요한 리소스" 참고
_legacy/              이전 와이어프레임 프로토타입 (다른 디자인, 참고용 보관)
```

## ⚠️ 필요한 리소스 — 폰트 1개

이미지·아이콘 **41개는 Figma에서 전부 자동으로 받아 `assets/`에 넣어뒀습니다.**
따로 넣어주실 건 **폰트 파일 하나**뿐입니다.

### Ownglyph PDH (온글잎 박다현체)

디자인 전체의 제목·라벨·캐릭터 대사에 쓰이는 손글씨 폰트입니다.
지금은 파일이 없어서 **Pretendard로 대체 표시**되고 있어요. (레이아웃은 정상)

**넣을 위치와 파일명 (둘 중 아무거나, 둘 다 넣어도 됨):**

```
assets/font/OwnglyphPDH.woff2      ← 권장 (용량 작고 빠름)
assets/font/OwnglyphPDH.ttf
```

파일만 저 이름으로 넣으면 코드 수정 없이 바로 적용됩니다.
(`css/style.css` 맨 위 `@font-face`가 이 경로를 보고 있습니다.)

> 파일명을 바꾸고 싶으면 `css/style.css`의 `@font-face { src: ... }` 경로만 고치면 됩니다.

### 참고: Pretendard

말풍선 본문·시간·팝업 텍스트에 쓰입니다.
지금은 CDN(jsDelivr)에서 자동으로 불러오고 있어서 **인터넷이 되면 그냥 잘 나옵니다.**
오프라인에서도 쓰고 싶으면 `assets/font/`에 Pretendard를 넣고
`css/style.css` 1번 줄의 `@import`를 로컬 `@font-face`로 바꿔주세요.

## Figma와 다른 점 / 남은 것

- 메시지 목록은 Figma처럼 절대 좌표로 고정하지 않고 **스크롤되는 흐름 배치**로 만들었습니다.
  (메시지를 실제로 보낼 수 있어야 해서) 초기 상태의 위치·간격은 시안과 동일합니다.
- 말풍선은 Figma의 `말풍선 배경 (stretch)` SVG를 그대로 늘려 쓰는 방식입니다.
  원본 SVG에 3.6MB짜리 그림자 패스가 들어 있어서, 같은 모양·같은 색으로 가볍게 다시 썼습니다.
- 대화 내용 요약 제목은 **키워드 규칙 기반**입니다 (`js/data.js`의 `SUMMARY_RULES`).
  실제로는 LLM 요약이 들어갈 자리라, 규칙에 안 걸리면 첫 메시지를 18자로 잘라 씁니다.
- 캐릭터 이름이 시안마다 달랐습니다(햄찌 / 멜랑 / 코치).
  말풍선 화자는 **햄찌**, 캐릭터 선택은 **멜랑·코치**로 시안 그대로 뒀습니다.
  확정되면 `js/data.js`의 `CHARACTERS`와 `CHAT_*`만 고치면 됩니다.
- 편지·마이 탭, 오늘운세·출석체크 버튼은 **주화면 범위 밖**이라 눌러도 반응하지 않습니다.
